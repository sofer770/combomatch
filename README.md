# ComboMatch - מחשבון צירופי מזון

אפליקציית ווב רספונסיבית (טלפון, טאבלט ומחשב) בעברית ו-RTL, לבדיקת צירופי מזון לפי כללי השיטה שהוגדרו באפליקציה.

## הפעלה

דרוש Node.js 18 ומעלה.

```bash
npm install
npm run dev          # שרת פיתוח: http://localhost:5173
npm test             # בדיקות יחידה למנוע החוקים ולאחסון (Vitest)
npm run build        # בנייה לתיקיית dist (אתר סטטי, אפשר להעלות לכל אחסון)
npm run build:single # קובץ HTML יחיד ועצמאי בתיקיית dist-single
```

בדיקות קצה לקצה (Playwright, 26 תרחישים כולל מובייל):

```bash
npm run dev &
node e2e/scenarios.mjs http://localhost:5173/
```

## התקנה בטלפון ופרסום

כל דחיפה לענף `main` בונה את האפליקציה ומפרסמת אותה ב-GitHub Pages (`.github/workflows/deploy.yml`).
בגרסה המפורסמת אפשר להוסיף את האפליקציה כאייקון למסך הבית (manifest ו-service worker בתיקיית `public/`),
והיא ממשיכה לעבוד גם בלי אינטרנט אחרי הכניסה הראשונה. הגופן כלול בקוד, ואין תלות באתר חיצוני.

## טכנולוגיות

React 18, TypeScript, Vite, Tailwind CSS, React Router. אחסון מקומי בדפדפן (localStorage), ללא הרשמה וללא שרת.

## מבנה

```
src/
  domain/types.ts        מודל הנתונים: Foods, FoodCategories, FoodFamilies, CombinationRules,
                         SavedMeals, MealItems, HistoryEntry (SearchHistory), AppSettings
  data/method-matrix.json  מטריצת הכללים שנגזרה ממסמך השיטה (המקור היחיד לכללים)
  data/methodRules.ts    המרת המטריצה לכללים: explicit/sourced=מאומת, inferred=טעון אימות, undefined=אין כלל
  data/seed.ts           משפחות, קטגוריות ו-96 מזונות התחלתיים
  engine/ruleEngine.ts   מנוע החוקים
  engine/alternatives.ts הצעת חלופות
  engine/search.ts       חיפוש בעברית (ניקוד, אותיות סופיות, כתיב מלא/חסר)
  storage/store.ts       שכבת האחסון (מוחלפת בקלות בבסיס נתונים בענן)
  pages/                 בית, תוצאות, ארוחות קבועות, כללים, היסטוריה, מזונות, הגדרות
```

## מנוע החוקים

1. כל מזון משויך למשפחה אחת או יותר.
2. נבדקים **כל** זוגות המזונות (2 עד 6 מזונות; בשלושה מזונות: א-ב, א-ג, ב-ג).
3. לכל זוג נבדקים כל צירופי המשפחות שלו מול המטריצה (הכללים סימטריים).
4. פתרון התנגשויות לפי חומרה: אדום > לא מוגדר > צהוב > ירוק. כלל אדום אחד הופך את כל הארוחה לאדומה. כלל חסר אינו מנוחש ומוצג "טרם הוגדר".
5. כל בדיקה נשמרת בהיסטוריה עם הכללים שהופעלו וגרסת הכללים.
6. חלופות: כל החלפה אפשרית נבדקת מחדש מול כל שאר רכיבי הארוחה, ומוצעות עד 3 שמובילות לירוק (או לצהוב כשהארוחה אדומה).

## עדכון הכללים בלי לשנות קוד

* במסך "כללים": לחיצה על משבצת במטריצה מאפשרת להגדיר, לערוך או למחוק כלל.
* ייבוא קובץ JSON (בפורמט הייצוא של האפליקציה או בפורמט `method-matrix.json`).
* לעדכון ברירת המחדל לכל המשתמשים: להחליף את `src/data/method-matrix.json` ולבנות מחדש.

## הבהרה

האפליקציה מבוססת על כללי צירופי מזון של השיטה ואינה מהווה ייעוץ רפואי או תחליף לייעוץ של איש מקצוע מוסמך.
